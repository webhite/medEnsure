# Django Project

A web application built with **Django 6.0.1** and **Python 3.13.3**.

---

## 🚀 Tech Stack

- **Python:** 3.13.3  
- **Django:** 6.0.1

- **OS:** Cross-platform (Linux / macOS / Windows)
